# Портфолио разработчика

Это мой личный сайт-портфолио, созданный для демонстрации моих навыков и проектов в области разработки программного обеспечения. Здесь я рассказываю о себе, своих услугах, технологиях, с которыми работаю, и показываю примеры реализованных проектов.

## 🚀 Демо

Посмотреть сайт в действии можно по ссылке:  
[https://zoest20009.github.io/portfolio/](https://zoest20009.github.io/portfolio/)

## ✨ Особенности

*   **Адаптивный дизайн**: Сайт корректно отображается на любых устройствах — от смартфонов до настольных мониторов.
*   **Структурированная информация**: Все ключевые разделы портфолио (обо мне, услуги, навыки, проекты, хобби, контакты) представлены в удобном для восприятия виде.
*   **Визуальное оформление**: Современный и минималистичный дизайн, который фокусирует внимание на контенте.

## 🛠️ Технологии

Сайт построен на классическом стеке веб-технологий:

*   **HTML5** — разметка страницы.
*   **CSS3** — стилизация и адаптивная верстка.
*   **JavaScript** — интерактивность и динамическое поведение элементов.
